
Chaque widget doit être défini dans un fichier à part.

Dans une classe, les constantes doivent être définies en tant qu'attribut statique de la classe.

Le projet doit contenir un router avec GoRouter.

Si le projet supporte le web, alors le routage doit appliquer la stratégie pour le web.

Le projet doit être par défaut internationnalisé en français et en anglais.

Définis une page d'erreur si ça doit supporter le web.

Définis une classe pour gérer les thèmes des widgets définis dans le projet. Utilise cette classe à la racine du projet.
